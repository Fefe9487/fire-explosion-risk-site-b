# 使用大量危險物廠場職災及違規紀錄查詢系統

公開網站：<https://fefe9487.github.io/fire-explosion-risk-site-b/>

本系統於 2026-10-19 分為兩個獨立網站：

- 本儲存庫：認識使用大量危險物廠場、相關規定及指引、事業單位公開紀錄查詢。
- [含統計系統](https://fefe9487.github.io/fire-explosion-risk-site/)：[fire-explosion-risk-site](https://github.com/Fefe9487/fire-explosion-risk-site)，保留完整舊版的裁罰統計、職災類型與分析功能。

分版前的 B 版原始碼保留於標籤 `before-system-split-20261019`（`007418d0338231956de79ae7cf785d4735835e68`）。

## 頁面

1. `index.html`：使用大量危險物廠場定義、操作說明、資料來源與查詢方法。
2. `gaps.html`：相關法規及官方技術指引，直接顯示完整清單，不含裁罰統計及職災類型統計分頁。沿用既有網址。
3. `query.html`：依名稱或統編查詢，候選名單只列有火災爆炸相關紀錄的公司。選定後顯示「未落實火災爆炸預防裁罰」及「發生火災爆炸職災」兩類。

`method.html` 是首頁說明的相容入口。頁面使用 `assets/site.css` 與既有圖片。

2026-11-12 起只保留火災爆炸相關裁罰與職災處分，已移除重大職災公開網資料、載入程式及來源入口，避免無法確認的來源重疊。另依使用者確認移除與原973個廠場清冊對照後新增的28家候選公司，及其57個廠場與相關公開紀錄。主要資料保留195筆裁罰、9筆職災處分；統編彙總另保留17筆裁罰、3筆職災處分。候選項目由169筆減為141筆，包含140家有統編公司及1筆缺統編項目。這些是資料列數，頁面件數仍按處分字號去重，兩類紀錄不可相加當成事故場次。

移除清單固定保存在 `data/company-exclusions.json`，以統編辨識公司，避免與同名但不同統編的公司混淆。清冊現為974個廠場，按有效統編合計680家公司，另3個廠場缺統編。裁罰年度仍為105–115年，職災年度仍為111–115年；此次僅移除指定28家公司，不另外縮成圖表的106–115年或排除缺統編項目。

火災爆炸裁罰的判斷沿用既有條文清單、已核對的第6條防火防爆敘述，以及同公司同處分字號的火災爆炸職災對照；職災只保留官方類型為「火災」或「爆炸」者。原公告全文與共同引用條文均保留。`data/query-rules.json` 不含排行、年度件數或全體統計。

本版範圍內的場所清冊保留作公司名稱、統編與場所配對；沒有任何可查相關紀錄的公司不出現在候選名單。查無結果不推定公司是否屬於使用大量危險物廠場，也不表示未曾發生事故或違規。原始來源快照保留於上游維護專案，本網站的公開JSON與離線檔只含本版範圍。

## 本機與驗證

```bash
python -m http.server 8765
```

開啟 `http://127.0.0.1:8765/index.html`。重建離線版與驗證：

```bash
node build-public-data.cjs
python pack_demo.py
node verify-pages.cjs
node verify-filters.cjs
node verify-company-names.cjs
python verify-browser.py
```

發布前一定要先跑 `verify-company-names.cjs`。同一統編仍是一家；統編不同不合併。公司名稱相同時，頁面會在名稱後加上場所。檢查若仍看到同名，就不要更新。

重新匯入上游資料後，先執行 `build-public-data.cjs`，再重建離線版與執行驗證。此工具先排除 `data/company-exclusions.json` 中的指定公司，再使用查詢頁的公司配對、期間及分類邏輯，清除不在範圍內的公開資料；請勿再匯入或打包已停用的資料來源。來源取得日期與來源最新處分日期不因本次範圍調整而更新。

瀏覽器驗證另需 Python Playwright 與 Chromium，預設連至 `http://127.0.0.1:8876`；先在另一個終端執行 `python -m http.server 8876`，或把其他本機網址傳給驗證程式。驗證會涵蓋正常頁面及完全斷網的離線檔，並將桌面與手機截圖寫入 `docs/verification-20261112/`。

`demo.html` 內嵌查詢資料、圖片、樣式及指引，預設顯示首頁，可在離線狀態切換頁面與查詢公司；外部法規、YouTube 影片和官方公告連結需連線。舊離線統計頁籤的網址會開啟指引頁。

本系統是瀏覽器端查詢。公開 JSON 及離線版含完整場所與紀錄資料；頁面不主動列出場所清冊。公開紀錄按同一統編合併，查無紀錄不代表未曾發生事故或違規，歷史紀錄不代表目前的安全程度。實際內容與法規適用請核對官方原文。

首頁、說明頁及離線展示檔使用使用者指定的 YouTube 影片：https://youtu.be/zdOFnnIJDhI 。本機剪輯版與同步字幕仍保留於 `assets/videos/`。
